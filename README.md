# Bible
A Bible app built with Python and Streamlit, offering a simple, interactive interface for reading and exploring Scriptures.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://jbc-bible-app.streamlit.app/)



#### Aim
+ To build a simple Bible app using Python and Streamlit that helps users read, search and study Scripture.

#### Structure
+ Single Verse Section
+ Miltiple Verse Section
+ Sudy Mode
	- Text Analysis

#### Packages
+ streamlit, pandas, spacy, textblob, neattext, nlt, altair, matplotlib
